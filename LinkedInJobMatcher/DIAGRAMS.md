## Resume/Retry Scenario

```
RUN 1:
    dotnet run -- analyze
    ?? Process posts 1-50 ?
    ?? Process post 51... CRASH!
    ?? Status in DB: 50 done, 51 partially

RUN 2 (Same Command):
    dotnet run -- analyze
    ?? Query: WHERE Status = 'Unprocessed' OR (Status = 'Failed' AND RetryCount < 3)
    ?? Finds: post 51 in retry queue
    ?? Processes: post 51 (retry)
    ?? Continues: posts 52, 53, 54...
    ?? All posts eventually processed ?

Key Point: Database checkpoint after each post ensures
no re-processing of successfully analyzed posts.
```
